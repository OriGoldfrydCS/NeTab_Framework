# Changelog

## v0.1.0

- Configurable schemas, active-record validation, and null padding.
- Empirical length and record proposals with independent reference banks.
- Relative, uniform, and absolute candidate selection.
- Markov, Tiny Transformer, and Hugging Face causal scorer interfaces.
- CPU training with checkpoint selection by validation NLL.
- CSV adapters, YAML configuration, CLI, and in-memory examples.

- Optional history-dependent candidate filters and automatic CPU/CUDA selection.
